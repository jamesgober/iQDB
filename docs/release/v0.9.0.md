# iqdb v0.9.0 — Release Candidate

**The last stop before 1.0.** v0.9.0 closes the crash-recovery test gap and captures benchmark baselines. There are no API changes — this is a confidence release ahead of the 1.0 freeze.

## What is iqdb?

An embedded vector database for Rust: exact and approximate similarity search, declarative filters, durable storage with tunable fsync and compression, an optional result cache, and an opt-in async surface — the integration layer over the iqdb crate family, all behind one small handle.

## What's new in 0.9.0

### Crash-recovery integration tests

The durable path inherits its framing, CRC, and WAL replay from `iqdb-persist`, which fuzzes and proptests those internally. v0.9.0 adds the recovery coverage at the `iqdb` level — corrupting the on-disk files directly and driving recovery through the public handle, so the §8 "Crash recovery" invariant is pinned end to end:

- **Torn WAL tail.** Two acknowledged writes, then junk appended after the last good frame. On reopen the torn tail is truncated to the last known-good offset: both prior records are recovered, and the log is left write-ready (a further write + clean close persists).
- **Corrupt snapshot.** A byte flipped in the payload region fails the open with `Error::Persist` (a checksum mismatch), rather than loading partial state.
- **Garbage file.** A non-database file is rejected with `Error::Persist`.

These live in `tests/recovery.rs`.

### Benchmark baselines

`criterion` baselines for the search hot path, captured on a developer machine (dim 64, 1 000 vectors):

| Benchmark | Time |
|-----------|------|
| `flat/search_dim64_n1000_k10` | ≈ 7.9 µs |
| `hnsw/search_dim64_n1000_k10` | ≈ 35.8 µs |
| `flat/upsert_dim64` (1 000 inserts) | ≈ 185 µs |

At a thousand vectors the exact flat scan is faster than HNSW — the graph index's traversal overhead only pays off at much larger corpora, which is exactly why flat remains both the recall ground truth and the right default for small datasets. Run them with `cargo bench --bench search`.

## Breaking changes

**None.** This release adds tests and records benchmark numbers; the public API, on-disk format, and behaviour are unchanged.

## Verification

Run on Windows x86_64 and on WSL2 Ubuntu (Rust stable); the same commands run in the configured CI matrix on Linux, macOS, and Windows:

```bash
cargo fmt --all -- --check
cargo clippy --all-targets --all-features -- -D warnings
cargo test
cargo test --all-features
cargo deny check
cargo audit
cargo bench --bench search
RUSTDOCFLAGS="-D warnings" cargo doc --no-deps --all-features
cargo +1.87 build --all-features
```

All green. Test counts with `--all-features`: 42 unit + 3 async + 12 persistence + 3 recovery + 2 property + 3 recall + 21 doctests.
